# Event: Sprint Review

The sprint is closing. As the Scrum Master, inspect the increment honestly:

1. Compare what was DELIVERED (merged PRs, closed tasks) against the **Sprint
   Goal** — met, partially met, or missed, with evidence (PR links).
2. List carry-over items (selected but not finished) — no masking; say why.
3. Post the review as a structured comment on the project (status update),
   readable by humans: goal, delivered, carry-over, notable events.
4. Deliverable: the same review content printed inline.
